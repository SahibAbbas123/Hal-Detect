## 1. 🏗️ Evolution of the HalDetect Verifier Engine (Iterations 1.0 $\to$ 2.5)

### **Iteration 1.0 — The Initial Heuristic Baseline (Early August 2026)**
* **Decomposition:** Naive regex sentence splitting (`.` and `\n`). Suffered from decontextualization, pronoun loss (e.g. *"He was born in..."*), and loss of temporal scope.
* **Routing:** Keyword and simple regex matching into 5 modalities (`QUANTITATIVE`, `TEMPORAL`, `ENTITY_ATTRIBUTE`, `CITATION`, `RELATIONAL`).
* **Verification:** 
  * Single-hop Wikidata SPARQL querying.
  * Simple SBERT sentence embeddings for predicate matching.
  * Off-the-shelf `DeBERTa-v3` / `BART-MNLI` for open relational fallback.
* **Vulnerabilities:** 0% coverage on macroeconomic data, severe property resolver false alarms, and failure on indirect multi-hop relationships.

### **Iteration 1.5 — The Bugfix & Calibration Epoch (Mid August 2026)**
* **Task #25 Core-Term Guard Fix (`property_resolver.py`):** Fixed the 0.35 similarity threshold bug that was falsely rejecting valid date synonyms (e.g. *"service start"* vs. *"inception"*).
* **Citation Dual-Emit Pairing:** Linked bibliographic claims to source-existence statements with a shared `{PAIR:citation_pair_NN}` suffix.
* **Date-Kind Normalization:** Implemented explicit calendar year extraction and range matching.

### **Iteration 2.0 — Category C Neuro-Symbolic Fortifications (Late August 2026)**
* **2-Hop SPARQL Graph Traversals (`temporal_ea_verifier.py`):** Enabled HalDetect to traverse intermediate Wikidata nodes (e.g., finding university affiliations, child relationships, or employer records across proxy nodes).
* **Quantitative Tier 2 (World Bank REST API) (`quantitative_tier2_verifier.py`):** Integrated live World Bank REST endpoints (`api.worldbank.org/v2`) with automated indicator mappings (`NY.GDP.MKTP.CD` for Nominal GDP, `NY.GDP.MKTP.PP.CD` for PPP GDP) and currency normalization.
* **SI Dimensional ALU (`dimensional_quantity_engine.py`):** Built deterministic mathematical unit-conversion ALUs (Kelvin↔Celsius, m/s speed of sound, transistor counts, qubit counts) with calibrated relative error margins ($\pm 2\%$).
* **Bidirectional Alias Lexicon (`alias_lexicon_resolver.py`):** Solved multilingual and acronym entity-linking failures (e.g. *"USA"*, *"America"*, *"United States"*).

### **Iteration 2.5 — Schema-Constrained 5-Tuple Pipeline (Present)**
* **`SchemaAtomizer` (`schema_atomizer.py`):** Upgraded from flat text to structured 5-tuples:
  $$\langle \text{Subject } (S), \text{ Predicate } (P), \text{ Object } (O), \text{ Temporal Scope } (T), \text{ Epistemic Mode } (M) \rangle$$
* Preserves grammatical tense (`HISTORICAL` vs `PRESENT`), polarity negation (`ASSERTED_TRUE` vs `NEGATED`), and epistemic hedging (`ASSERTION` vs `HYPOTHESIS`).

## 3. ⚖️ Evolution of Evaluation Methodology & Baselines

### **Stage 1: The Raw Accuracy Fallacy**
* **Method:** Measured simple binary accuracy ($\text{Correct} / N$).
* **Flaw Discovered:** Because the initial dataset was 88% True, an "Always-True" degenerate baseline scored 88% without doing any verification.

### **Stage 2: Introduction of 3-Valued Logic ($\mathcal{L}_3$) & MCC**
* **Reform:** Adopted **3-Valued Logic** (`TRUE`, `FALSE`, `UNVERIFIABLE`) and **Selective Accuracy** (accuracy on answered claims, penalized by coverage).
* **Metric Invariant (Rule R3):** Mandated **Matthews Correlation Coefficient (MCC)** as the primary integrity metric:
  $$\text{MCC} = \frac{TP \times TN - FP \times FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}$$
  *(Degenerate Always-True or Always-False baselines collapse to $\text{MCC} = 0.000$).*

### **Stage 3: The 4-Way Competitive Horse Race (Track 1 $N = 1,000$)**
* Evaluated 4 distinct architectural paradigms on identical 1,000 claims:
  1. 🛡️ **HalDetect 2.0 (Full-Routed):** **97.60% Selective Accuracy** ($\text{MCC} = +0.952$, $P(\text{FALSE}) = 97.4\%$, $R(\text{FALSE}) = 97.8\%$).
  2. ⚙️ **Semi-Routed Baseline:** 73.60% Accuracy ($\text{MCC} = +0.473$, misses arithmetic/World Bank).
  3. 🌐 **SOTA Dense+Hybrid RAG:** 69.20% Accuracy ($\text{MCC} = +0.400$, falls into lexical overlap traps).
  4. 🧠 **Non-Routed DeBERTa NLI:** 60.00% Accuracy ($\text{MCC} = +0.260$).
* **Statistical Significance:** McNemar Chi-Squared Test proved HalDetect beats SOTA RAG with $\chi^2 = 278.09 \ (p < 10^{-60})$.

### **Stage 4: Multi-Model Auditing & Taxonomy Classifier Ablations (Track 2 $N = 1,798$)**
* **7-Model Factuality Matrix:** Audited Qwen 2.5, Mistral 7B, Qwen Coder, DeepSeek-R1 Distill, Gemma 31B, GPT-OSS 120B, and MiniMax M3.
  * HalDetect caught **31 out of 31 Kaggle hallucinations ($100\%$ Recall on errors)**, while SOTA RAG and MiniCheck-7B caught **0 out of 31 ($0\%$ Recall)**.
* **Taxonomy Classifier Ablation:** Proved HalDetect's symbolic router achieves **88.8% accuracy at $<0.05\text{ms}$ latency**, while frontier LLMs (Gemma, GPT-OSS, MiniMax) scored only 20%–58% due to mode collapse and citation blindness while taking 400–1000ms.
