\chapter{Track 2 Standardized 50-Prompt Generative Benchmark Suite}
\label{app:prompts_suite}

This appendix provides the complete standardized 50-prompt benchmark suite evaluated across seven foundation models (Qwen 2.5-7B, Mistral-7B-Instruct, Qwen 2.5-Coder-7B, DeepSeek-R1-Distill-7B, Gemma31B:Cloud, GPT-OSS 120B, and MiniMax Text-01 M3). The suite yielded 1,798 atomic propositions across five technical and factual domains.

\label{sec:app_hardware_prompts}
% ******************************************************************************

\begin{enumerate}
    \item \textit{"Detail the fabrication process node, transistor count, CPU core configuration, GPU core count, and memory bandwidth of the Apple M3 Max processor."}
    \item \textit{"Provide the architecture, CUDA core count, Tensor core count, HBM3 memory capacity, and TDP of the NVIDIA H100 SXM5 GPU."}

    \item \textit{"State the core count, thread count, L3 cache size, and default TDP of the AMD EPYC 9654 Genoa server processor."}
    \item \textit{"Provide the fabrication process, performance core count, efficient core count, and maximum turbo frequency of the Intel Core i9-14900K processor."}
    \item \textit{"Detail the GPU architecture, stream processor count, infinity cache size, and VRAM bandwidth of the AMD Radeon RX 7900 XTX."}
    \item \textit{"State the fabrication node, Neural Engine TOPS rating, and unified memory capacity of the Apple M2 Ultra system-on-chip."}
    \item \textit{"Describe the architecture, integer core count, and vector extension width of the Tenstorrent Wormhole PCIe processor."}

\end{enumerate}
