## What This Project Is

HalDetect: a taxonomy-routed hallucination-detection pipeline for LLM-generated text. Five claim types (CITATION, TEMPORAL, QUANTITATIVE, ENTITY_ATTRIBUTE, RELATIONAL), each routed to a type-specific verifier. This session did not touch verifier code or gold labels — it produced a reference document from an existing 140-claim dataset export.

**Scope of this session:** purely a formatting/reference task. No new verification, no new gold labels, no code changes.

## C. Key Findings — Ranked by Evidence Strength

1. **The 140-claim set cleanly decomposes into the five-type taxonomy with only one ambiguous case.** Q10-2 ("WWI was caused by the assassination... in 1914") was flagged as a candidate for splitting into two claims (a TEMPORAL date claim and a RELATIONAL causal claim) but was left as single TEMPORAL claim per the existing claim ID structure, since splitting would break alignment with whatever gold-labeling already exists against these IDs.

2. **Two claims are plausible UNVERIFIABLE candidates, not confirmed.** Gr10 (sea-level rate through 2024) is a post-training-cutoff empirical claim; Gr14 (CRISPR/Nature claim) lacks enough specificity (no paper name, date, or journal issue) to route to a verifier confidently. These were flagged inline, not adjudicated — that adjudication should happen against actual gold labels, not against this formatting pass.

3. **Distribution is consistent with prior batches.** RELATIONAL remains the plurality class (67/140, ~48%), matching the pattern already documented in Phase 2 gold labels (RELATIONAL 64/109 in the authoritative Phase 2 set per the prior handoff). This is corroborating, not new, evidence — worth noting only because it means this new 140-claim set doesn't look structurally different from the existing gold-labeled corpus.

4. **This session's classifications are NOT gold labels.** They were produced by Claude during a formatting task, not verified against Wikidata/CrossRef/Semantic Scholar, and not reviewed claim-by-claim by the author. They should be treated as a first-pass taxonomy assignment requiring the same human gold-labeling discipline as every other batch in this project — not as ground truth.
