\section{Dataset Evolution and Forensic Lineage}
\label{sec:dataset_lineage}
% ******************************************************************************

Constructing a reliable benchmark for hallucination detection requires rigorous provenance tracking to avoid class imbalance artifacts and evaluation leakage. The benchmark corpus evolved across five distinct developmental phases:

\begin{enumerate}
    \item \textbf{Phase 1: Exploratory Genesis (Batch 1, $N=125$):} Initial natural assertions extracted from factual question answering. While effective for validating the initial 5-modality router, this partition suffered from extreme negative scarcity (only 8 gold \texttt{FALSE} assertions, representing a severe 6.4\% false-class base rate).
    \item \textbf{Phase 2: Entity Disambiguation and Bug B Discovery (Phase 2 Gold, $N=126$):} Sourced to evaluate structured entity resolution. Forensic auditing uncovered two foundational phenomena: (a) entity ambiguity collisions (e.g., musical bands sharing names with historical artifacts), resolved via the candidate-commit SBERT gate ($s > 0.60$), and (b) source-existence misattributions (e.g., claim \texttt{Q22\_C01} regarding FAO food insecurity trends, corrected to gold \texttt{FALSE}).
    \item \textbf{Phase 3: Synthetic Hard Negatives and Perturbations (Batch 3, $N=122$ + 84 Negatives):} Introduced structured entity and numerical perturbations to stress-test arithmetic ALUs across magnitude variations and temporal shifts.
    \item \textbf{Phase 4: Expansion Corpora v2 ($N=731$) and v3 ($N=2,130$):} Scaled coverage across sovereign macroeconomic metrics and scientific constants.
    \item \textbf{Phase 5: Symmetrical Master Benchmark ($N = 1,000$):} Symmetrically balanced partition comprising exactly 500 gold \texttt{TRUE} and 500 gold \texttt{FALSE} claims across all five verification modalities.
\end{enumerate}

\section{Comparative Baseline Systems}
\label{sec:baseline_systems}
% ******************************************************************************

We benchmark HalDetect against three primary comparative paradigms:
\begin{enumerate}
    \item \textbf{Non-Routed Baseline:} Monolithic pipeline that passes all propositions directly to a DeBERTa-v3-large cross-encoder without taxonomy categorization or specialized ALUs.
    \item \textbf{Semi-Routed Baseline:} Coarse 3-class routing that partitions claims into Numeric, Temporal, and Open Text, using heuristic string search without dimensional unit normalization.
    \item \textbf{Modern 2026 SOTA RAG:} Dense+lexical hybrid retrieval (SBERT embedding ranking over top-4 Wikipedia candidate titles) combined with a DeBERTa-v3 cross-encoder running under calibrated entailment margins.
\end{enumerate}

\section{Evaluation Metrics and Mathematical Derivations}
\label{sec:eval_metrics}
% ******************************************************************************

Let $N$ denote total claims, $N_{\text{ans}}$ denote answered claims, and $N_{\text{abstain}}$ denote claims assigned an epistemic \texttt{UNVERIFIABLE} verdict. We report:
\begin{itemize}
    \item \textbf{Coverage:} Proportion of claims for which the system returns a confident binary verdict:
    \begin{equation}
        \text{Coverage} = \frac{N_{\text{ans}}}{N} = \frac{N - N_{\text{abstain}}}{N}
    \end{equation}
    \item \textbf{Selective Accuracy:} Accuracy computed strictly over the answered partition:
    \begin{equation}
        \text{Acc}_{\text{sel}} = \frac{1}{N_{\text{ans}}} \sum_{i=1}^{N_{\text{ans}}} \mathbb{I}(\hat{y}_i = y_i^*)
    \end{equation}
    \item \textbf{Matthews Correlation Coefficient (MCC):} The balanced, chance-corrected geometric mean quality metric:
    \begin{equation}
        \text{MCC} = \frac{TP \times TN - FP \times FN}{\sqrt{(TP+FP)(TP+FN)(TN+FP)(TN+FN)}}
    \end{equation}
    where $\text{MCC} \in [-1, +1]$, with $+1$ indicating perfect prediction and $0$ representing random guessing.
    \item \textbf{Youden's J Statistic:} Diagnostic informedness metric:
    \begin{equation}
        J = \text{Sensitivity} + \text{Specificity} - 1 = \frac{TP}{TP+FN} + \frac{TN}{TN+FP} - 1
    \end{equation}
    \item \textbf{Expected Calibration Error (ECE):} Partitioning predictions into $M=10$ equal-frequency confidence bins $\{B_1, \dots, B_M\}$:
    \begin{equation}
        \text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|
    \end{equation}
    \item \textbf{Brier Score:} Mean squared error of probabilistic predictions:
    \begin{equation}
        \text{Brier} = \frac{1}{N} \sum_{i=1}^N (c_i - \mathbb{I}(\hat{y}_i = y_i^*))^2
    \end{equation}
    where $c_i \in [0, 1]$ represents model confidence.
    \item \textbf{Wilson Score 95\% Confidence Intervals:} For all observed proportions $\hat{p} = k/n$:
    \begin{equation}
        w = \frac{\hat{p} + \frac{z^2}{2n} \pm z \sqrt{\frac{\hat{p}(1-\hat{p})}{n} + \frac{z^2}{4n^2}}}{1 + \frac{z^2}{n}}
    \end{equation}
    where $z = 1.95996$ for the two-sided 95\% confidence level.
    \item \textbf{Statistical Significance Testing:} Paired McNemar test with Edwards continuity correction:
    \begin{equation}
        \chi^2 = \frac{(|b - c| - 1)^2}{b + c}
    \end{equation}
    where $b$ denotes claims where HalDetect is correct and baseline is incorrect, and $c$ denotes claims where baseline is correct and HalDetect is incorrect.
\end{itemize}

\section{Gold-Labeling Protocol and Zero-Leakage Static Audit}
\label{sec:labeling_protocol}
% ******************************************************************************

Gold verdicts were established through independent expert annotation cross-validated against authoritative primary databases (Wikidata SPARQL, World Bank OData, and CrossRef). 

To ensure absolute scientific integrity and eliminate evaluation leakage, all verification scripts are statically inspected prior to benchmark execution using an automated Python Abstract Syntax Tree scanner (\texttt{\_leak\_check()}), confirming that no predictor function accesses ground truth labels during inference.
