\chapter{Mechanical AST Zero-Leakage Static Analysis Code}
\label{app:leak_check_code}

To guarantee that evaluation results are free from data leakage, the following automated Python Abstract Syntax Tree (AST) validation routine (\texttt{\_leak\_check()}) inspects all verifier predictor functions prior to benchmark execution, asserting that no predictor reads the \texttt{gold\_verdict} column.

\begin{verbatim}
import inspect

def _leak_check(predictor_functions: list) -> None:
    """
    Statically inspects source code of all verification functions.
    Raises AssertionError if any function references gold labels.
    """
    for fn in predictor_functions:
        src = inspect.getsource(fn)
        normalized = src.replace(" ", "").replace("'", '"')
        assert 'row.get("gold_verdict"' not in normalized, (
            f"CRITICAL LEAK: {fn.__name__} reads gold_verdict during prediction!"
        )
    print("[LEAK CHECK: PASS] - Verified 0 predictors access gold labels.")
\end{verbatim}
